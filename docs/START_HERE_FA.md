# راهنمای فعلی پروژه

راهنمای کامل و به‌روز فارسی در `START_HERE_FA.html` است؛ آن را با مرورگر باز کنید. مقالهٔ فعلی در `paper/manuscript.pdf` و پاسخ داوری در `RESPONSE_TO_REVIEW.md` قرار دارد. برای بازسازی تحلیل‌ها از ریشهٔ پروژه `python revision.py analyze` و برای بررسی صحت `python revision.py verify` را اجرا کنید.
